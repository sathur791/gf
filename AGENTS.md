# Workspace Guidelines: Kalai Kah Birthday

## Automatic Deployment
- Whenever any changes or fixes are made to this project, you must automatically test and deploy them to Vercel production:
  1. `npm run build`
  2. `npx vercel --prod --yes`
- Live production domains:
  - https://kalaikahbirthday.vercel.app
  - https://kalai-kah-birthday.vercel.app
